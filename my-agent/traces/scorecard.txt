채점표: tool-definition.md의 "실행 전 채점 기준"
판정: 통과 / 실패 / 해당 없음

| 채점 기준 | trace-01 | trace-02 | trace-03 | trace-04 |
| 스키마 준수 (sku 문자열, 허용된 warehouse_id만) | 통과 | 통과 | 통과 | 통과 |
| 호출 성공 (성공 반환 또는 정해진 오류 코드) | 통과 | 통과 | 통과 | 통과 |
| 결과 사용 가능성 (available_quantity, checked_at만 근거) | 통과 | 통과 | 통과 | 통과 |
| 실패 처리 (오류 뒤 수량을 짐작하지 않고 정해진 행동) | 해당 없음 | 해당 없음 | 해당 없음 | 해당 없음 |

- trace-01: 요청 "BUSAN-02 창고의 SKU A-17 재고를 알려 줘". 맞는 답.
- trace-02~04: 요청 "부산 3번 창고의 A-17 재고를 알려 줘". 모델이 BUSAN-02로 바꿔 넣어 부산 2번 재고를 답했다. 사용자가 물은 창고가 아니므로 틀린 답이다.
- 그런데도 채점표로는 모두 통과다. BUSAN-02는 허용된 값이고, 오류가 나지 않아 실패 처리 칸은 해당 없음이 된다.
- 채점표에 "사용자가 말한 창고를 그대로 넣었나"를 보는 칸이 없어서 이 실수를 잡지 못했다.
- trace-mcp-01은 재고 도구가 아니라서 이 채점표를 쓰지 않았다.
